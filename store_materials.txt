# Card Draft 스토어 등록 정보 텍스트 세트

## 1. 앱 이름 (App Name)
Card Draft

## 2. 간단한 설명 (Short Description - 80자)
5칸 필드 전투와 3대 세력 필살기를 활용한 로그라이크 덱빌딩 RPG

## 3. 자세한 설명 (Full Description - 4,000자)
Card Draft는 5칸 필드 전투와 전략적 덱 구축을 결합한 싱글플레이 로그라이크 덱빌딩 RPG 게임입니다.

[핵심 게임 특징]
• 5칸 필드 턴제 전투 시스템: 적 대표 선봉 유닛을 제어하고 돌파 피해를 가하는 정밀한 전략 전투
• 개성 넘치는 3대 시작 세력:
  - 인간 세력: 소환과 버프 중심의 '왕국의 집결' 필살기
  - 엘프 세력: 카드 드로우와 마나 획득 중심의 '바람의 순환' 필살기
  - 언데드 세력: 아군 희생과 정수 전환 중심의 '죽음의 계약' 필살기
• 빌드 태그 시너지 연계: 화염, 드로우, 사망, 버프, 저체력, 소환의 6가지 빌드 시너지 및 강력한 3연계 콤보 피니시
• 모험과 성장의 런 진행: 맵 노드 선택, 위험한 전투, 카드 보상, 이벤트, 상점 및 15종의 앵커 유물 수집
• 자동 런 저장 지원: 전투 중 손패와 필드, 진행 상황이 실시간 안전 저장되어 언제든 이어서 플레이 가능

지금 당신만의 카드 덱을 드래프트하고 국경지대의 보스들을 제압하세요!
