# Card Draft: Three Factions 개인정보처리방침

최종 업데이트: 2026년 8월 16일

본 개인정보처리방침은 `Card Draft: Three Factions`(이하 "앱")의 개인정보 및 데이터 처리 방식을 설명합니다.

## 1. 앱의 기본 운영 방식

앱은 오프라인 싱글플레이 카드 게임입니다. 앱 이용을 위해 회원가입, 로그인, 서버 접속, 온라인 계정 생성이 필요하지 않습니다.

앱은 이름, 이메일 주소, 전화번호, 주소록, 위치정보, 사진, 음성, 결제정보 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.

## 2. 앱이 기기에 저장하는 데이터

앱은 게임 진행과 설정 유지를 위해 아래 데이터를 이용자 기기 내부에만 저장할 수 있습니다.

| 구분 | 저장 항목 | 목적 |
| --- | --- | --- |
| 게임 진행 데이터 | 진행 중인 런, 덱, 카드, 유물, 전투 상태 | 이어하기 및 게임 진행 복원 |
| 설정 데이터 | 사운드 설정, 튜토리얼 진행 상태, 해금 상태 | 이용자 설정 유지 |

이 데이터는 외부 서버로 전송되지 않으며, 개발자 또는 제3자가 접근하지 않습니다.

## 3. 개인정보 수집 및 제3자 제공

앱은 개인정보를 수집, 판매, 공유하거나 제3자에게 제공하지 않습니다.

앱은 광고 SDK, 분석 SDK, 위치 기반 서비스, 연락처 접근, 카메라, 마이크, 푸시 알림, 계정 생성 기능을 사용하지 않습니다.

## 4. 데이터 보관 및 삭제

앱의 저장 데이터는 이용자 기기 내부에 보관됩니다.

이용자는 다음 방법으로 앱 데이터를 삭제할 수 있습니다.

- 앱 삭제
- 기기 설정에서 앱 데이터 삭제
- 앱에서 제공되는 데이터 초기화 기능 사용

앱은 별도의 서버 계정을 생성하지 않으므로, 개발자가 별도로 보관하거나 삭제해야 하는 서버 측 개인정보는 없습니다.

## 5. 아동 개인정보

앱은 아동을 대상으로 개인정보를 수집하지 않습니다. 앱은 이용자의 나이, 이름, 연락처 또는 위치정보를 수집하지 않습니다.

## 6. 개인정보처리방침 변경

앱의 데이터 처리 방식이 변경되는 경우, 본 문서를 업데이트하여 변경사항을 안내합니다.
