# 시작 전략 비교 기록

2026-09-09 · Godot 4.6.3 · 별도 `--test-data-dir` 사용

## 구성과 호환성

여섯 전략은 각각 카드 10장과 기존 유물 하나로 시작한다. 데이터 원본은 `data/starting_strategies.json`이다. 요청안의 언데드 혈투에 있던 `first_aid`는 인간 전용이므로, “해당 세력 또는 공용 카드” 조건에 맞춰 공용 회복 카드 `healing_potion`으로 보정했다. 엘프 순환은 요청한 `forest_archer` 3장을 포함해 정확히 10장이다.

선택은 시작 버튼을 누르기 전 저장하지 않는다. 시작 시 전략 ID·주력 태그·시작 덱·시작 유물을 런에 저장한다. 이어하기는 저장 내용을 사용하고, 전략 ID가 없는 기존 런과 전략을 생략한 호출은 종전 구성을 유지한다. 학습 런은 기존 단계별 개방을 유지한다.

## 고정 시드 자동 플레이

시드 20260909~20260918을 모든 전략에 동일하게 적용했다. 각 시드에서 일반·엘리트 우선 경로를 각각 실행했다. 공통 전투 수치는 변경하지 않았다. 총 120회 중 120회 완주했으며 진행 정지는 없었다. 전략별 전패 및 반복 정지 차단 조건은 발생하지 않았다.

아래 전투 지표는 두 경로를 합친 값이다. 턴·장비·희생·드로우는 전투당 평균, 첫 턴 승리·피니시는 전투 건수다. 드로우는 시작 손패를 포함한 실제 손패 추가 수이며 손패 초과 폐기는 제외한다.

자동 플레이가 모든 전략에서 완주하므로 이번 결과만으로 난이도가 적절하다고 판단할 수 없다. 선택 정책에 따른 편향이 있으며, 특히 빠른 승리와 피니시 빈도는 신규 사용자 플레이에서 다시 확인해야 한다. 자동 승률을 맞추기 위한 공통 능력치 조정은 하지 않았다.

## 회귀와 화면 검증

- 회귀 테스트 1,199개 통과: 전략 데이터, 선택 중 저장 무변경, 실제 시작 구성·저장 복원, 잘못된 ID 거부, 구형 런, 학습/바로 시작, 새 연계 우선순위와 기존 연계 유지, 실제 덱에 따른 보상 전환, 지표 복원 포함.
- 1280×720 데스크톱과 390×844 모바일에서 전략 선택·덱 펼쳐보기·하단 시작 버튼을 캡처해 확인했다.
- 실제 카드 입력 핸들러를 호출한 네 시나리오에서 인간 군단은 유닛 전개, 인간 정예는 장비 2회와 지원 주문, 엘프 순환은 통찰·화살통·질풍 사격과 드로우 연계, 엘프 기습은 순찰자 연속 소환과 소환 연계를 기록했다. 이는 자동 입력 시나리오이며 사람의 직접 조작 검증을 대신하지 않는다.
- 그래픽 캡처 종료 시 기존 ObjectDB 경고와 모바일의 리소스·텍스처 해제 오류가 남는다. 화면 시나리오는 통과했으나 그래픽 종료가 깨끗하지 않다. 회귀 및 비교 로그에는 스크립트 오류가 없었다.

신규 사용자의 이해도·재미·10~15분 플레이 시간과 사람의 직접 조작에 따른 전략 차이는 별도 플레이테스트가 필요하다. 재실행 방법은 [실행과 테스트](run-and-test.md)를 참고한다.
