# 직접 제작한 음악과 효과음

> 초기 주파수 합성 실험의 기록이다. 사용자가 이 제작 방식을 거절하여 현재는 [로컬 음악·효과음 생성 모델](local-model-audio.md)로 교체했다. 아래 1,242개 검사 결과와 녹음 수치는 이전 합성 팩의 결과이며 새 음원의 검증 결과가 아니다.

2026-09-10. 외부 음원·녹음·샘플·사운드폰트 없이 수학적 합성으로 제작했다. 작곡 음표와 음색 합성 코드는 `tools/compose_original_audio.py`에 있다.

## 제작물

- **Embers at the Border**: D minor 기반, 80 BPM, 16마디 / 48초. 메뉴는 부드러운 패드와 종소리 계열의 짧은 선율을 사용한다.
- **전투 4개 레이어**: 기본 아르페지오, 긴장 타악기, 마무리 금관 계열, 낮은 체력의 심장 박동. 길이·화성·박자가 같아 게임의 기존 적응형 믹서로 함께 재생한다.
- **효과음 39개**: 클릭, 카드 뽑기와 사용, 세력별 소환·장비·공격, 주문, 회복, 연계, 필살기, 승리·패배 등 모든 런타임 키에 연결했다.
- 모든 파일은 `assets/audio/original_v1/`에 있다. `PROVENANCE.md`와 `manifest.json`에 출처, 제작 도구, 레벨, 해시를 기록했다.

기존 외부 제작 오디오는 새 런타임 로더에서 사용하지 않으며 내보내기 제외 목록에 추가했다. 파일 누락 시에는 기존 코드의 직접 합성 효과음으로 대체한다.

## 다시 만들기

Python 3, NumPy, FFmpeg가 필요하다.

```bash
python3 tools/compose_original_audio.py
```

48초 곡 하나와 네 레이어, 39개 효과음을 다시 생성한다. 인코딩 후 디코딩한 샘플의 유한값과 클리핑 여부를 검사한다. 기존 프로젝트 저장에는 접근하지 않는다.

## 엔진 재생 검증

```bash
xvfb-run -a godot --path . -s res://tests/godot/capture_original_audio.gd -- --test-data-dir=/tmp/card-draft-audio-check
```

메뉴 음악 → 전투 음악과 효과음 10개 → 메뉴 복귀를 실제 AudioStreamPlayer와 버스에서 재생한다. 지정한 폴더의 `engine_audio.wav`는 Godot Master 버스에서 녹음한 결과다. 헤드리스가 아닌 그래픽 실행이 필요하다.

음량 조절은 기존 BGM/SFX 버스와 설정을 사용한다. 소프트웨어 출력 검증과 사용자의 스피커·이어폰에서 듣는 최종 청감 검수는 구분한다.

검증 결과: 전체 회귀 검사 `PASS 1242 assertions`, 실제 엔진 재생·복귀 검사 통과. Master 버스 녹음에서 신호와 유한 샘플을 확인했으며 최대 진폭은 0.556, RMS는 0.087이었다.
