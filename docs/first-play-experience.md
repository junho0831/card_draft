# 첫판 이해와 손맛

## 목적과 범위

기존 5단계 학습 중 첫 전투를 직접 소환하고 공격하는 경험으로 만든다. 전투 수치·덱·보상·일반 런의 추천 조작은 유지한다. 예산은 0원이며 기존 아트·음원·피해 숫자·체력바를 활용한다.

## 행동 안내

상단에는 현재 가능한 행동 한 문장을 표시하고 도움 보기는 해당 위치 하나를 강조한다. 도움은 선택·소환·공격·턴 종료를 대신 수행하지 않는다. 이미 배치된 전장을 우선하므로 구형 저장에서도 불가능한 연습을 강요하지 않는다. 다른 합법적인 행동과 조기 승리를 허용한다. 소환한 일반 유닛은 다음 턴부터 공격하므로 필요할 때 턴 종료를 먼저 안내한다. 첫 전투의 행동 소진 자동 턴 종료를 끄고 직접 종료하도록 한다.

| 단계 | 안내 | 성공 피드백 | 막혔을 때 |
|---|---|---|---|
| 소환 | 손패의 유닛 카드를 눌러 소환하세요 | 유닛 등장, 마나 감소, 소환음 | 사용 가능한 카드만 추천; 없으면 공격 또는 턴 종료 |
| 모바일 확인 | 카드를 눌러 확인한 뒤 다시 눌러 소환하세요 | 첫 탭은 확대, 두 번째 탭은 소환 | 다른 카드로 선택 변경 가능 |
| 아군 선택 | 공격 가능한 아군을 눌러 선택하세요 | 아군 선택 표시와 공격 대상 강조 | 공격 불가 유닛은 제외 |
| 선봉 공격 | 적 선봉을 누르세요: 살아남은 적만 반격합니다 | 피해 숫자·처치 효과, 실제 완료 기록 | 선택만으로 완료 처리하지 않음 |
| 영웅 공격 | 적 영웅을 눌러 직접 피해를 주세요 | 영웅 체력 감소·타격음 | 새 공격자가 필요하면 소환 또는 턴 종료 |
| 턴 종료 | 지금 가능한 행동이 없습니다: 턴 종료를 누르세요 | 적 행동 후 다시 조작 | 도움 자체는 턴을 넘기지 않음 |

선봉 처치 후에는 영웅을 노릴 수 있다는 안내를 표시한다. 처치한 적은 반격하지 않는 현재 규칙을 설명하며, 상호 피해를 무조건 받는다고 안내하지 않는다. 기존 장비 대상 선택과 취소는 유지한다.

## 저장

선택적 런 필드 `first_play_actions`에 실제 `summoned`, `unit_attacked`, `vanguard_defeated`, `hero_attacked`를 기록한다. 전투 저장과 함께 보존한다. 소환 효과로 선봉을 처치한 경우도 기록한다. 필드가 없는 구형 저장은 현재 손패·마나·공격 가능 상태에 따라 안내하며 과거 행동을 추측해 완료 기록을 만들지 않는다. 정상 승리를 추가 연습으로 지연하지 않는다.

- 자동 검증: 결과는 아래 실행 결과에 기록한다. 신규 사용자의 이해도나 재미를 증명하지 않는다.
