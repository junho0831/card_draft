# 최종 UI 지시서 검토와 적용 결정

2026-09-13. 사용자가 제공한 두 지시서의 방향은 채택하되, 현재 동작과 기준 해상도에 맞춰 단계적으로 적용한다. 두 번째 첨부 파일은 26번 업적 항목의 문장 중간에서 끝나므로 그 이후 요구는 추정하지 않았다.

## 현재 구조

| 화면 | 컨트롤러 |
| --- | --- |
| 메인 | `main.gd`, 가로 `cinematic_menu.gd` |
| 세력·전략 | `race_selection_screen.gd` |
| 원정 지도 | `map_screen.gd` |
| 전투·대상 선택 | `battle_screen.gd` |
| 보상·상점 | `reward_screen.gd`, `shop_screen.gd` |
| 이벤트·휴식·결과 | `event_screen.gd`, `rest_screen.gd`, `run_result_screen.gd` |
| 도감·보관함 | `compendium_screen.gd`, `collection_screen.gd` |
| 제거·강화 | `deck_edit_screen.gd` |
| 성장·설정 | `meta_upgrade_screen.gd`, `settings_screen.gd` |

공통 요소는 `ui_factory.gd`, `ui_tokens.gd`, `ui_styles.gd`, `card_view.gd`, `card_race_styles.gd`다. 기존 일반/전투 버튼 스타일과 카드 생성 코드에 중복이 남아 있다. 새 `fantasy_components.gd`는 장식 카드와 버튼을, `battle_presentation.gd`는 크기와 별도 정보 창을 담당한다. 이름과 경로를 전부 다시 바꾸는 리팩터링은 이번 수정에 섞지 않는다.

전체 화면 셸은 세로 스크롤이며, 전투는 600px 이하 세로 화면과 1100px 이상 가로 화면을 구분한다. 세로 태블릿은 별도 손패 확인 분기를 사용한다. `battle_screen.gd`에는 전투 상태와 UI 생성이 함께 있어 표시 도우미부터 추출했으며, 계산·저장·AI를 동시에 옮기지는 않았다.

## 적용

- 전투: 큰 외곽 패널 제거, 원화와 카드 확대, 정보 창, 대상 강조와 취소. 구체적인 결과는 [전투 기준안](battle-presentation.md).
- 빈 슬롯: 기본 테두리와 배경을 더 약하게 표시한다. 다음 소환 위치는 구분하며 기존 클릭 규칙은 유지한다.
- 모바일 손패: 사용 가능한 카드의 반복 상태 문장을 숨긴다. 사용 불가 사유와 첫 학습에서 선택한 카드의 사용 안내는 유지한다.
- 보상: 가로 화면의 카드별 선택 버튼을 제거한다. 카드 클릭으로 선택하고 하단 버튼 하나로 확정한다.
- 도감: 텍스트 목록을 그림 카드 그리드로 교체한다. 모바일 2열, 가로 4열이며 세력·종류·이름/효과 검색과 카드 상세 창을 제공한다. 유물 목록은 접을 수 있다.
- 업적: 실제 업적 데이터와 구현이 없어 메뉴에서 숨긴다. 미구현 안내 라우트는 구형 호출 호환을 위해 남긴다.

## 그대로 적용하지 않는 지시

- 카드 1.5~1.8배 고정 확대: 카드와 CTA가 viewport에 들어가는 크기로 계산한다.
- 가로 전투를 모두 세로로 쌓기: 720px 높이에서 카드가 작아지므로 영웅을 전장 옆에 유지한다.
- 미래 지도 노드를 거의 숨기기: 경로 판단을 위해 이름은 읽히게 둔다.
- 조작 설명 전부 제거: 첫 학습과 모바일 두 번 누르기 안내는 필요할 때 유지한다.
- 도감 미보유 카드 정보를 무조건 감추기: 기존 도감은 공개 정보다. 없는 해금 조건을 만들거나 프로필 규칙을 바꾸지 않는다.
- 지시서의 HP·가격·보상 예시: 실제 서비스 계산값을 사용하며 수치를 새로 고정하지 않는다.

## 후속 단계

아직 전체 UI 전면 개편 완료가 아니다. 전투 기준 검증 후 세력 선택·모바일 메인, 보상 carousel·상점 상품 상세, 제거/강화 카드 선택, 이벤트·휴식·결과 순으로 진행한다. 각 화면의 가로와 세로를 함께 검증한다. 이번 커밋에서 이 후속 작업을 구현했다고 표시하지 않는다.

## 검증

모든 실행은 별도 `--test-data-dir`를 사용한다. 주요 전투 1280×720·390×844 실제 렌더링과 입력, 도감 검색·상세·닫기, 보상 확정·상점 구매·저장 불변 검사를 수행한다. 5개 해상도 전체에 대한 새 도감 검증과 실제 모바일 브라우저 성능, 신규 사용자 측정은 별도로 남는다.

이번 적용 후 Godot 4.6.3 전체 회귀 **1325개**, 도감·보상·상점 UI 확인 **14개**가 통과했다. 기존 종료 시 리소스 해제 경고는 남는다.
