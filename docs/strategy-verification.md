## 저장 격리

모든 검증은 명시적인 `--test-data-dir`를 사용한다. 테스트 진입점은 절대 경로가 없으면 실행을 거부하고, 실제 적용할 런·프로필 경로를 출력한다. Snap 실행에서도 하위 캡처 프로세스에 같은 인자를 전달한다. 이전 검증에서 덮어쓴 개인 저장은 복원하지 못했으며, 이번 검증은 별도 `/tmp` 폴더에서만 수행했다.

## 화면 검증

1920×1080, 1280×720, 1024×768, 800×1280, 390×844에서 메뉴부터 결과까지, 아군 대상 선택을 포함한 51개 PNG를 생성했다. 데스크톱과 모바일 대상 강조·취소·유물 선택 화면을 눈으로 확인했다. 모바일 대상 선택 중에는 상단에도 취소 버튼을 제공한다.

세로 화면 캡처는 종료 시 CanvasItem/ObjectDB 및 그래픽 리소스 해제 경고가 남는다. 캡처 생성은 완료되었으며 이 경고의 원인은 아직 확정하지 않았다. 회귀 테스트와 자동 플레이에는 스크립트 오류가 보고되지 않았다.

Godot 4.6.3에서 학습 회귀를 포함해 1,124개 검증을 통과했다. 첫 막 경로, 단계별 기능 개방, 장비 선택 저장 복원, 추천 장비 수령, 다음 전투 첫 손패 장비 보장, 나머지 카드와 시작 유물의 일회성 개방, 완료 후 일반 진행 기본값, 기존 런 호환을 검사했다.

## 2026-09-09 학습 안내 보완

두 번째 전투의 안내를 아군 유무, 장비 손패, 마나, 실제 장착, 실제 2연계 성공에 따라 바꾸었다. 장비 대상을 고르다가 취소하면 완료로 기록하지 않으며, 실제 수행한 연습은 런 저장에 보존한다. 선택한 장비 ID를 저장하고 여러 장비가 있어도 해당 장비를 첫 손패에 우선 배치한다. 모바일 390×844에서 대상 선택 안내를 확인했다.
