# 변경 원정: 카드 100장 확장

## 구성과 플레이 방향

기존 카드에 인간·엘프·언데드·중립 각 25장, 총 100장을 추가한다. 유닛 60장, 주문 20장, 장비 20장이다. 신규 시작 덱이나 필살기를 만들지 않고 기존 보상·상점·도감 풀을 확장한다. 학습 시작 덱, 체력, 마나, 필드 5칸, 지도 길이는 그대로 유지한다.

- 인간: 전열 강화, 방패와 장비, 보급과 회복으로 전장을 유지한다.
- 엘프: 드로우, 즉시 공격, 사용 순서에 따른 피해로 공격 기회를 만든다.
- 언데드: 희생, 사망 효과, 자해와 회복을 교환한다.
- 중립: 각 세력 덱을 연결하는 방어·보급·장비 선택지를 제공한다.

전체 수치와 효과는 [카드 목록](frontier-catalog.md)에 기록한다. `python3 tools/content/build_frontier_review.py`로 로컬 검토 화면 `build/frontier-100/index.html`을 다시 만들 수 있다. 각 카드는 독립적인 ID와 아트를 가지며, 같은 역할의 카드 일부는 효과 연산을 공유한다. 100개의 완전히 새로운 규칙을 도입하는 업데이트는 아니다.

## 아트

카드별로 내장 이미지 생성 도구를 사용한 독립적인 세로 일러스트를 제작한다. 기존 작품의 캐릭터·로고나 UI를 이미지 안에 복제하지 않는다. 프레임·이름·수치는 기존 Godot 카드 UI가 그리며, 도감의 2.5D 뷰어에서도 같은 일러스트를 사용한다.

[아트 제작 기록](frontier-art-manifest.json)에 카드 ID, 실제 제작 프롬프트, 생성 상태와 원본 SHA-256을 남긴다. `assets/card_art/cards/<id>.png`가 원본이다. 이미지 모음은 검토용이며 개별 카드 원본을 대신하지 않는다.

PNG 원본은 보존하고 Godot 임포트에서 최대 변 길이 768, 손실 압축 품질 0.85를 사용한다. 가로 모바일에서 카드가 작게 그려진다고 원본 1024×1536 텍스처 100장을 그대로 메모리에 올리지 않도록 한다.

## 실제 타격 연결

`impact_profile`은 실제 공격에 사용되는 연출 계열이다. 손패 선택만으로 타격을 재생하지 않는다. 주문과 소환 피해는 효과가 실행되는 지점에서, 유닛 공격은 기존 공격 실행기에서 재생한다. 장비를 부착하면 그 유닛의 타격 계열도 바뀌며 저장 후 재개에도 유지한다.

| 계열 | 시각 연출 | 소리 방향 |
|---|---|---|
| 금속 | 짧은 대각선 베기와 불꽃 | 칼·방패 충돌 |
| 화살 | 가는 직선 궤적과 작은 충격원 | 기존 무기 충돌음 공유 |
| 불꽃 | 주황색 중심 폭발과 잔불 | 불꽃 충돌 |
| 얼음 | 차가운 방사형 파편 | 얼음 파열 |
| 번개 | 보라색 꺾인 섬광 | 전기 균열 |
| 암흑·독 | 안으로 수축하는 보라·녹색 고리 | 짧은 저음 충돌 |
| 뼈 | 밝은 파편 | 뼈와 갑옷의 충돌 |
| 혈기 | 붉은 베기 | 낮고 짧은 충돌 |
| 신성 | 금색 이중 고리와 빛줄기 | 맑은 차임 |
| 바람 | 옅은 관통 궤적 | 기존 무기 충돌음 공유 |
| 돌 | 무거운 중심 폭발과 충격원 | 중량 충돌 |

12계열 모두 별도 2D 노드와 짧은 Tween으로 표현하며 연출 후 임시 노드를 제거한다. 보통 공격에 새로운 전체 화면 섬광을 추가하지 않는다. 100개의 소리를 동시에 관리하는 대신 카드 무기·재질에 맞는 계열 음원을 공유한다. 새 타격음에는 일반 공격과 같은 재생 우선순위, 85ms 중복 간격, −5dB 음량을 적용한다.

새 음원은 얼음·암흑·번개 3종이다. 화살 전용음은 50스텝 생성 두 번에서도 신호 검사 기준에 미달해 배포하지 않는다. 화살과 바람은 기존 `sword_hit` 생성 음원을 공유하고, 시각 궤적을 구분한다. 음원은 MOSS 생성 모델의 파일을 사용한다. Python은 모델 실행과 원본 자르기·페이드·인코딩에 사용하며 주파수를 조합한 대체 음원을 제작하는 방식은 사용하지 않는다. 음원별 생성 조건·라이선스·해시는 오디오 디렉터리의 JSON에 기록한다. 무음·비정상 수치·클리핑 검사를 통과하지 못한 생성 결과는 적용하지 않는다.

## 데이터와 호환성

`tools/content/build_frontier_set.py`가 명시적인 카드 정의로 `data/frontier_cards.json`을 작성한다. `--publish`는 100장 아트가 모두 있는지 확인한 후 기존 `data/cards.json`에 병합하고 도감 설명을 갱신한다. 기존 카드 ID와 저장 덱은 변경하지 않는다.

신규 효과는 `src/battle/frontier_effects.gd`가 처리한다. 기존 카드의 전용 처리기는 유지한다. 유닛의 사망 효과·장비 계열은 전투 스냅샷에 함께 저장한다. 선택 대상이 유효하지 않으면 자해 비용을 포함해 효과를 적용하지 않는다. 대상 확정 이전에는 기존 UI 규칙대로 카드와 마나를 소비하지 않는다.

## 검증 범위

모든 실행에 별도 `--test-data-dir`를 지정한다. 신규 효과 검사, 실제 전투의 장비/희생 선택·취소·저장 복원, 12계열 효과 종료 후 정리, 기존 전체 회귀 검사를 구분한다. 기존 카드 풀과 확장 카드 풀의 동일 시드 자동 플레이는 진행 정지와 명백한 퇴행을 찾는 용도다.

자동 검사 통과는 사람의 재미·밸런스 평가를 대신하지 않는다. 100장 확장에 따른 보상 선택의 복잡성, 실제 휴대폰 가독성·청감, 각 세력 승률과 10~15분 완주 시간은 별도 플레이 관찰이 필요하다. 실측하지 않은 값은 달성했다고 기록하지 않는다.

## 확인된 결과

- 카드 ID·아트 ID·이미지 SHA-256 각각 신규 100개가 중복 없이 존재한다.
- 이미지 100장의 모바일용 임포트 파일 합계는 약 10.02MiB다. 원본 PNG 합계는 약 258.9MiB이며 별도로 보존한다. 이전 크기를 유지하던 임포트 캐시는 재생성했다.
- 844×390 가로 화면의 새 장비 확인과 390×844 도감에서 기울이기·복귀·세로 스크롤·닫기 입력 검사를 통과했다. 데스크톱 Godot에서 해당 크기로 렌더링한 결과이며 실물 휴대폰 검증을 의미하지 않는다.
- 새 유닛의 실제 공격·반격 결과와 피해 미리보기 일치를 844×390과 1280×720에서 확인했다. 세 번째로 사용하는 조건부 피해 카드는 그 카드 자체를 사용 횟수에 포함해 미리 계산한다.
- Android API 36 에뮬레이터의 2340×1080 가로 화면에서 세력 필터·목록 중앙 스와이프·신규 유닛과 장비의 상세 보기·세로 스크롤·고정 닫기 버튼을 실제 ADB 입력으로 확인했다. 최종 QA APK의 저장 경로는 `com.card_draft.mobileqa/files/mobile-qa-0914`이며, GDScript 오류는 없었다. 셰이더 캐시 재컴파일 경고는 남아 있다. 실물 휴대폰 검증은 아니다.
- 확장 전후 기본 덱 자동 플레이 6개 케이스를 [비교표](frontier-playthrough-results.md)와 원본 JSON에 기록했다.

오디오 초기화는 기존 생성 음원을 먼저 읽도록 변경했다. 로컬 Godot에서 초기화 함수 1회 측정은 변경 전 19,767ms, 변경 후 19ms였다. 전체 앱 시작 시간이나 실제 휴대폰 측정은 아니다. 오래된 음원 제작 도구는 명시적으로 합성 모드로 실행할 수 있다.

카드 보관함에는 신규 100장 필터를 추가하고, 카드와 크게 보기 버튼의 겹침을 수정했다. 카드 도감은 844px 가로 화면에서 세 열을 사용하며 상세 창에도 2.5D 뷰어를 연결했다. 상세 카드 한 장을 2배 해상도로 렌더링해 캐시하므로 고밀도 화면에서 글자의 흐림을 줄이고, 기울일 때마다 카드 UI를 다시 그리지 않는다.

Godot 4.6.3 전체 회귀 검사 3,011개 통과. 배포 음원 16파일(BGM 3곡·효과음 13종)의 디코딩·해시·무음·클리핑 검사 통과. 엔진의 음악 전환·효과음 이벤트 17개 재생과 Master 녹음을 확인했다(18.19초, peak 0.6123, RMS 0.1090). 신규 타격 효과 12종의 임시 노드 정리 검사도 통과했다. 기존 테스트 종료 시 CanvasItem/ObjectDB 정리 경고는 남아 있다.

```bash
# 기본 데이터·효과·저장·UI 회귀 검사
godot --headless --path . -s res://tests/godot/run_tests.gd -- --test-data-dir=/tmp/frontier-regression
# 새 카드의 2.5D 확인 창과 도감 입력
xvfb-run -a godot --path . -s res://tests/godot/card_inspection_test.gd -- --test-data-dir=/tmp/frontier-inspection --frontier-cards
# 실제 전투 피해와 가로 화면
xvfb-run -a godot --path . -s res://tests/godot/frontier_combat_capture.gd -- --test-data-dir=/tmp/frontier-combat-landscape --landscape
# 타격 계열 12종과 효과 종료 후 정리
xvfb-run -a godot --path . -s res://tests/godot/frontier_fx_capture.gd -- --test-data-dir=/tmp/frontier-fx
```
