# 설정

## 추가한 조절 항목

- **배경음악 / 효과음:** 각각 0~100%. 0%는 해당 소리만 음소거한다. 기존 믹싱을
  100% 기준으로 유지하며 전투 중 음악 볼륨 변화가 사용자 음소거를 해제하지 않는다.
- **전투 연출:** 풍부하게(준비·돌진·반동), 간결하게(즉시 타격 효과),
  최소화(타격 숫자·소리는 유지하고 돌진·섬광·입자를 줄임).
- **전장 자동 이동:** 항상 따라가기(대상 중앙으로 이동), 화면 밖 대상만(최소 이동),
  끄기. 가로 전장에 적용된다. 끄기에서도 직접 스크롤과 전열 이동 버튼은 작동한다.
- **타격 미리보기:** 전투 연출 바로 아래 버튼을 누르면 별도 창에서 현재 설정으로 자동 재생한다.
  다시 재생·닫기 버튼을 제공하며, 재생 중에도 닫을 수 있다. 기존 카드 그림·타격 효과·효과음을 사용한다.
  별도 시각 샘플이므로 전투 피해나 런 상태는 변경하지 않는다.
- **프로필 초기화 확인:** 확인창의 초기화 버튼을 눌러야 초기화된다. 취소하거나
  확인창을 닫으면 프로필은 유지된다. 진행 중 런 삭제 기능을 새로 추가한 것은 아니다.

AI 턴 속도·전체 화면·큰 화면용 UI 크기 설정은 유지한다. 이번 범위에는
30/60 FPS 선택, 모바일 글자 크기, 진동 설정을 포함하지 않았다.

## 저장과 공통 처리

기존 `battle_cutscene` 값을 유지하고 `reduced_battle_fx`로 최소화 여부를 저장한다.
구형 저장의 켜기는 풍부하게, 끄기는 간결하게로 복원한다. 자동 이동 기본값은
`outside`, 음량 기본값은 1.0이다. 음량은 범위를 제한하고 잘못된 설정값은 기본값으로 복구한다.

음량은 AudioManager의 BGM/SFX 버스에서 적용하며 적응형 음악용 MusicMix 버스와
분리한다. 슬라이더를 놓거나 설정 화면을 떠날 때 저장한다. 연출·이동 선택은 즉시 저장한다.
슬라이더 영역은 자체 드래그를 처리하고, 나머지 영역에서는 기존 페이지 스크롤을 유지한다.
설정 드롭다운은 누를 때 바로 열지 않고 손을 뗄 때 연다. 드롭다운 위에서 시작한
스와이프가 페이지 이동으로 이어지고, 이동 후 짧게 누르면 선택 목록이 열린다.

## 검증

모든 실행은 별도 `--test-data-dir`에서 수행했다.

```bash
godot --path . -s res://tests/godot/settings_controls_test.gd -- --test-data-dir=/tmp/card-draft-settings
godot --path . -s res://tests/godot/touch_scroll_test.gd -- --test-data-dir=/tmp/card-draft-settings-touch
godot --path . -s res://tests/godot/battle_presentation_lifecycle_test.gd -- --test-data-dir=/tmp/card-draft-settings-motion
godot --headless --path . -s res://tests/godot/run_tests.gd -- --test-data-dir=/tmp/card-draft-settings-regression
```

- Godot 4.6.3: 전체 회귀 2,325개 통과.
- 설정 검사: 구형/잘못된 설정, 독립 음량·음소거, 저장 복원, 3가지 미리보기,
  초기화 취소·확정, 자동 이동 끄기와 수동 이동, 최소 연출의 실제 피해 및 효과 정리.
- 기존 스크롤 검사와 연출 완료·화면 재구성·메뉴·복원 검사 통과.
- 설정 화면은 802×390 및 390×844에서 렌더링하고 미리보기 버튼 입력을 검사했다.
- 2026-09-22 실물 Samsung SM-G965N(Android 10)의 별도 QA 앱에서 ADB 터치로
  슬라이더를 조절했다. 배경음악 41%, 효과음 67%가 화면과 격리된 프로필 파일에
  동일하게 반영됐고 세로 화면의 미리보기 창과 다시 재생·닫기 버튼 표시를 확인했다.
  캡처: `build/mobile-qa-buttons-2026-09-22/03-settings.png`, `04-preview.png`.
- 이어서 가로 화면의 설정 중앙 스와이프, 미리보기 열기·닫기, 초기화 확인창 취소,
  세력 선택→학습 런 시작→지도→첫 전투 진입을 실제 기기에서 확인했다.
  캡처: `08-preview-landscape.png`, `12-reset-confirm.png`, `15-battle.png` (같은 폴더).
- 드롭다운 위 스와이프가 목록을 먼저 여는 문제를 발견해 공통 버튼 처리를 수정했다.
  Godot 4.6.3의 격리된 802×390 및 390×844 설정 검사에서 스와이프 이동,
  목록 오작동 방지, 이후 탭으로 목록 열기를 확인했다.
- 폰 사용을 다시 허용받은 뒤 수정본을 QA 앱에 재설치했다. 드롭다운 위 스와이프와
  이후 탭으로 목록 열기를 실물에서 재검증했다. 풍부한 미리보기의 재생→닫기도 작동했다.
  실물 캡처만으로 닫는 순간의 애니메이션 진행 상태까지 판정하지는 않았다.
- 카드 확인 취소가 손패·마나·양측 전장을 보존함을 저장값으로 확인했다. 소환,
  마나 부족 사용 차단, 턴 종료, 아군 선택 후 적 영웅 공격, 가로→세로→가로 전환,
  도움 보기의 전투 상태 보존과 첫 학습 전투 승리→다음 지도 이동을 확인했다.
  세로의 피해 예고 6→4와 실제 공격 후 HP가 일치했다. 가로의 영웅 오른쪽 가장자리
  터치는 HP 8→7을 한 번 적용하고 공격권을 소모했다.
- 상세 증거와 제한은 [실물 QA 기록](mobile-qa-2026-09-22.md)에 남긴다. 공격 시
  `can_process` 엔진 오류가 로그에 발견되어 이번 결과를 전체 무오류 통과로 보지는 않는다.
- 사람의 손가락 조작감과 청취 평가는 미검증이다. 녹음/파형으로 음량을 재측정한 것은
  아니며 자동 검사에서는 엔진 오디오 버스의 음량·음소거 적용을 확인했다.
