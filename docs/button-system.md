# 공통 버튼 규격

버튼 색과 크기를 분리한다. 같은 동작 종류는 주요/보조/위험 색상에 관계없이 같은
높이·글자 크기·안쪽 여백을 사용한다. 폭은 화면과 열 배치에 맞춰 결정한다.

| 종류 | 논리 높이 | 글자 크기 | 용도 |
| --- | --- | --- | --- |
| action | 52px | 16px | 확인, 구매, 선택, 닫기, 설정 선택기 |
| compact | 44px | 14px | 상단 메뉴, 정보, 전열 이동 |
| icon | 44×44px | 14px | 아이콘 전용 동작 |
| multiline | 64px | 16px | 제목과 설명 두 줄, 하단 행동 도크 |

`ui_tokens.gd`가 수치를, `button_metrics.gd`가 적용을 담당한다. `UiFactory`와
`BattleStyles`에서 함께 사용한다. 일반 버튼의 명시적인 줄바꿈은 두 줄 규격으로 처리한다.
긴 한 줄 제목은 줄바꿈으로 버튼을 키우지 않고 말줄임하며 전체 문구는 툴팁에 남긴다.
기존 별도 도움말 툴팁은 유지한다. 상태별 내부 여백을 같게 하고 일반 버튼의 호버 확대를
제거해 클릭·비활성·선택 변경으로 버튼이 커지거나 글자 위치가 바뀌는 일을 줄인다.
OptionButton도 공통 처리에서 손을 뗄 때 열도록 맞춘다. 누르자마자 팝업을 열어
상위 스크롤이 스와이프를 받지 못하는 문제를 막는다.

메뉴·설정·가로 전투·세력 선택의 동작 버튼·보상 선택·상점 구매에 적용했다.
카드 자체, 영웅 초상, 지도 노드, 큰 그림을 담은 선택 타일은 일반 버튼 규격에서 제외한다.
UI Factory는 기존 80px 초과 타일과 정사각형 지도 노드의 크기를 보존하며, 상단 아이콘은
명시적으로 icon 규격을 사용한다.

새 일반 버튼은 스타일 적용 후 `ButtonMetrics.apply(button, "action")`를 호출한다.
이후 화면 코드에서 font_size나 높이를 덮어쓰지 않는다. compact/icon은 명시적으로 지정한다.

```bash
godot --path . -s res://tests/godot/button_metrics_test.gd -- --test-data-dir=/tmp/card-draft-buttons
```

위 검사는 390×844, 802×390, 1280×720에서 실제 배치와 긴 문구·비활성 상태의 크기
유지를 확인한다. 가로 전체 화면 캡처, 667×375 전투 입력, 가로·세로 설정 검사도 수행했다.
실물 휴대폰의 조작감 검증은 별도다.

Godot 4.6.3에서 공통 규격 검사, 마지막 가로 화면 검사와 전체 회귀 2,325개가 통과했다.
대표 캡처는 `build/common-buttons-2026-09-22/`에 있다.
실물 Samsung SM-G965N에서 가로 메뉴·설정·초기화 확인창·첫 전투 진입을 추가로
확인했다. 상세 범위와 남은 실물 검사는 [설정 검증](settings.md#검증)에 기록한다.
