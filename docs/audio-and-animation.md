# 사운드와 전투 애니메이션

## 제작과 연결

기존 메뉴·전투곡과 8종의 생성 음원을 유지하고 탐험 BGM과 중량 타격·필살기 음원을 추가했다. 변경 원정 확장을 포함해 총 BGM 3곡, 효과음 13종이다. 보스 전용곡은 포함하지 않았고, 활 전용음은 생성 품질 검사에 미달해 기존 무기 충돌음을 공유한다. 음악은 ACE-Step 1.5, 효과음은 MOSS-SoundEffect v2의 텍스트 기반 실제 오디오 출력이다. 외부 곡이나 특정 음악가를 참조하지 않는다. 유료 API를 사용하지 않으며 모델은 게임에 포함하지 않는다.

원본 프롬프트, 시드, 모델 버전, 출력 해시는 `assets/audio/local_models_v1/`의 같은 이름 JSON에 있다. 라이선스와 기존 제작 환경은 [로컬 모델 음원](local-model-audio.md)에 기록한다. 사용 허용 라이선스와 생성 결과의 저작권 비침해 보증은 구분한다.

| 상황 | 오디오 | 시각 피드백 |
| --- | --- | --- |
| 메뉴·세력 선택·결과 | `menu_theme` | 기존 화면 전환·선택 강조 |

| 보스 전투 | `battle_base` (일반 전투곡 공유) | 강한 공격과 필살기 강조 |
| 클릭·카드 드로우/사용 | `ui_click`, `card_play` | 기존 카드 확대와 이동 |
| 소환·장비 | `summon` | 카드 착지·확산 고리·장비 축소 |
| 일반 검격·반격 | `sword_hit` | 돌진·타격 궤적·붉은/주황 충격·반동 |
| 일반 엘프 공격 | `sword_hit` (기존 타격음 공유) | 초록색 곡선 궤적 |

| 강타·직접 공격 | `heavy_hit` | 큰 충격·짧은 정지·화면 흔들림 |

승리·패배 등 기존 이벤트는 음원 팩을 공유한다. 모든 이벤트를 서로 다른 신규 파일로 제작한 것은 아니다. 카드 효과와 전투 수치, 시작 덱, 저장 형식은 이 작업에서 변경하지 않는다.

## 재생 규칙

- 같은 탐험곡을 쓰는 지도→상점 등에서는 재생 위치를 유지한다. 곡을 바꾸면 새 곡이 0.6초 동안 서서히 커진다.
- 보스→일반 전투에서는 일반 전투곡을 복원한다. 전투를 떠나면 전투곡을 종료한다. 이미 재생 중인 전투에 상태 갱신이 들어와도 곡을 처음부터 재생하지 않는다.
- 강타·필살기가 재생되면 음악 전용 하위 버스 `MusicMix`를 최대 5dB 낮췄다가 복구한다. 사용자가 설정한 상위 `BGM` 음량은 수정하지 않는다.
- 일반 타격은 대상 주변을 강조한다. 강타에서만 화면 전체의 짧은 빛을 사용한다.
- 회복·사망·필살기 이펙트는 입력을 가로채지 않는다. 사망 파편은 전장 슬롯과 독립되어 다음 유닛의 위치·투명도를 바꾸지 않는다.
- 효과 종료 시 임시 노드와 Tween을 정리한다. 테스트/헤드리스의 연출 생략 규칙은 유지한다.

## 실행 검증

아래 명령은 프로젝트 루트에서 실행한다. 모든 Godot 실행에 별도 저장 경로를 지정한다.

```bash
godot --headless --path . -s res://tests/godot/run_tests.gd -- --test-data-dir=/tmp/card-draft-av-regression
xvfb-run -a godot --path . -s res://tests/godot/capture_original_audio.gd -- --test-data-dir=/tmp/card-draft-av-audio
xvfb-run -a godot --path . -s res://tests/godot/capture_av_presentation.gd -- --test-data-dir=/tmp/card-draft-av-desktop
xvfb-run -a godot --path . -s res://tests/godot/capture_av_presentation.gd -- --test-data-dir=/tmp/card-draft-av-mobile --mobile
```

오디오 검사는 메뉴→일반 전투→보스→탐험→메뉴 전환과 효과음을 실제 AudioStreamPlayer로 재생하고 Master 출력을 `engine_audio.wav`에 녹음한다. 연출 검사는 테스트 전장을 사용해 기존 공격 연출 진입점과 새 이펙트를 실행하며 `heal.png`, `death.png`, `ultimate.png`를 저장한다. 연출만 실행했을 때 전투 상태가 그대로인지, 공격 카드의 크기·회전이 복원되는지, 임시 이펙트가 정리되는지도 검사한다.

```bash
/home/junho/.cache/card-draft-audio/2026-09-11/acestep/.venv/bin/python tools/validate_audio_pack.py \
  --preview-dir build/audio-review-2026-09-13
```

음원 검사는 Ogg를 디코딩해 유한 샘플·무음·클리핑·길이·출처 해시를 확인한다. `validation.json`과 모든 곡을 직접 재생할 수 있는 미리듣기 페이지를 만든다.

## 검증 범위

신호 검사와 엔진 재생/화면 캡처는 자동 검증이다. 실제 휴대폰 스피커·이어폰에서의 타격감, 장시간 반복 시 피로도, 저사양 모바일 프레임 속도는 사람이 별도로 확인해야 한다. 기존 엔진 종료 시 ObjectDB/CanvasItem 관련 경고는 이 작업의 임시 이펙트 정리 검사와 별개다.

## 변경 원정 확장 — 2026-09-15

얼음 `ice_hit`, 암흑 `shadow_hit`, 번개 `lightning_hit` 3종을 MOSS 모델로 생성했다. [변경 원정](expansion/frontier-100.md)의 타격 계열 12종에 연결하며, 화살·바람 계열은 기존 `sword_hit` 음원을 공유한다. 실제 피해가 발생하는 지점에서 재생하고, 같은 주문의 기본 타격음과 중복 재생하지 않는다. 일반 공격과 같은 재생 우선순위와 중복 간격을 적용한다.

오디오 매니저는 생성된 Ogg를 초기화 단계에서 먼저 읽는다. 정상 게임 실행에서 파일이 있는 소리를 다시 파형 합성하느라 기다리지 않으며, 이전 제작 도구만 명시적인 합성 모드를 사용한다.

최종 검증: Godot 4.6.3 회귀 검사 3,011개, 음원 파일 16개 검사 통과. 음악 전환과 효과음 이벤트 17개를 실제 엔진에서 재생하고 Master 출력을 녹음했다. 검증 데이터는 `/tmp/frontier-final-theme-regression`, `/tmp/frontier-final-engine-audio`로 분리했다. 사람의 청취 평가는 미실시다.
