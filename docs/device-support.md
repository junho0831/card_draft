# 휴대폰 지원 조건과 성능 검증

작성 기준: 2026-09-15, 코드 `02c4f52`의 Android 설정과 100장 확장 검증 기록.

## 사용자에게 안내할 내용

> Android 7.0 이상, 64비트 ARM 환경, OpenGL ES 3.0 지원 기기가 필요합니다. 가로 화면으로 플레이합니다. 현재 실물 휴대폰의 최소·권장 성능은 검증 중이며, 기종별 원활한 실행을 보장하는 목록은 아직 없습니다.

Android 버전만 충족한다고 설치·성능이 모두 보장되지는 않는다. 64비트 프로세서라도 운영체제가 32비트인 기기는 현재 배포 구성에 맞지 않는다. Play 스토어의 해당 기기 설치 가능 여부도 확인해야 한다.

## 확인된 설치 조건

| 항목 | 현재 조건 | 근거 |
|---|---|---|
| Android | 7.0/API 24 이상 | `android/build/config.gradle`의 minSdk 24. 내보내기 설정은 기본값 사용 |
| CPU/운영체제 ABI | arm64-v8a | `export_presets.cfg`의 Android 아키텍처 설정 |
| 그래픽 | OpenGL ES 3.0 지원 | `project.godot`의 GL Compatibility 렌더러 |
| 화면 | 가로 화면, 콘텐츠 스크롤 | 현재 화면 구성과 입력 검증 |
| RAM·여유 저장 공간 | 제품 최소값 미확정 | ARM64 출시 빌드의 실기기 최대 메모리·설치 크기 측정 필요 |

그래픽 조건은 [Godot 4.6의 내보낸 프로젝트 요구 사항](https://docs.godotengine.org/en/4.6/about/system_requirements.html#mobile-device-smartphone-tablet-minimum)을 참고한다. 엔진 예제의 RAM·저장 공간 수치를 이 게임의 최소 사양으로 사용하지 않는다. 출시 때는 실제 AAB의 manifest와 Play Console 기기 카탈로그로 설치 조건을 다시 확인한다.

## 어떤 폰부터 검증할 것인가

다음은 성능을 확인할 **검증 후보**이며 지원 확정 목록이나 구매 추천이 아니다. 현재 실물 기기의 FPS, 최대 메모리, 발열 측정값은 모두 없다. 동일 이름도 지역·RAM·칩셋 모델을 따로 기록한다.

| 검증 구간 | 후보 예시 | 확인할 목적 | 현재 상태 |
|---|---|---|---|
| 낮은 성능 구간 | Galaxy A13, 보유한 RAM 4GB 기기 | 도감 스크롤·이미지 로딩·메모리 부족 여부 | 미검증 |
| 중간 성능 구간 | Galaxy A34 5G, A54 5G | 일반 플레이와 2.5D 카드 뷰어의 기준 확보 | 미검증 |
| 이전 고성능 구간 | Galaxy S20 FE | 장시간 전투와 연속 효과 확인 | 미검증 |

우선 RAM 6GB 이상 기기를 검증 기준으로 잡되, 이는 시험 계획상의 여유 목표다. 측정 전에는 이를 확정 권장 사양으로 배포하지 않는다. 예산 0원 조건에 맞춰 보유하거나 테스터가 가진 기기로 진행하며, 기기를 새로 구매할 필요는 없다.

## 이미 확인한 것과 아직 모르는 것

- Android API 36 에뮬레이터 2340×1080에서 도감·상세 보기·스크롤·닫기 입력을 확인했다. x86_64 QA 앱 결과이며 ARM64 휴대폰의 성능 증거는 아니다.
- 신규 카드 100장의 모바일 임포트 파일은 합계 약 10.02MiB다. 이것은 파일 용량이며 실행 중 RAM·GPU 메모리 사용량이 아니다.
- 오디오 초기화 19ms는 로컬 PC에서 함수 1회 측정한 결과다. 휴대폰 앱 시작 시간으로 안내하지 않는다.
- 테스트의 기능 통과와 종료 시 리소스 경고는 별개다. 반복 진입에서 메모리가 계속 증가하는지 실기기로 확인해야 한다.
- 최신 확장 내용을 담은 ARM64 출시 빌드의 다운로드·설치 크기, FPS, 발열과 배터리 소모는 미측정이다. QA APK 크기를 스토어 다운로드 크기로 안내하지 않는다.
- iPhone과 모바일 웹은 별도 검증 대상이다. Android 결과를 그대로 적용하지 않는다.

상세 근거는 [100장 확장 검증 기록](expansion/frontier-100.md)을 참고한다.

## 지원 확정 절차

실행에는 별도 `--test-data-dir`와 QA 앱 ID를 사용하고 로그에 기록된 실제 저장 경로를 확인한다. 출시와 같은 ARM64·렌더러·리소스를 사용하며, 기기 모델 번호·OS·RAM·빌드 커밋·해상도를 남긴다.

1. 앱을 완전히 종료한 상태에서 3회 실행해 첫 조작까지의 시간을 기록한다.
2. 도감 147장 목록을 왕복 스크롤하고 카드 상세를 20회 열고 닫는다.
3. 양쪽 필드가 찬 전투에서 소환·공격·전체 피해·희생·12계열 연출을 확인한다.
4. 한 런을 완료하고 총 20분 이상 플레이하며 전후의 프레임 시간·최대 PSS 메모리·발열·입력 지연을 기록한다.
5. 같은 경로를 반복해 메모리의 지속 증가, 비정상 종료, 화면 깨짐을 확인한다.

초기 합격 목표는 입력 누락·크래시 없음, 조작 중 프레임 시간 p95 33.3ms 이하(30fps 기준), 20분 뒤에도 같은 기준 유지다. 60fps 권장은 p95 16.7ms 이하를 별도로 확인한다. 로딩 구간과 실제 조작 구간을 나눠 측정하고 긴 멈춤의 횟수·최대 시간도 함께 적는다. 이는 앞으로 검증할 기준이며 달성 결과가 아니다.

| 기기/모델 번호 | OS/RAM | 빌드/해상도 | 시작 시간 3회 | 조작 p95/최대 프레임 시간 | 최대 PSS | 20분 뒤 결과 | 판정 |
|---|---|---|---|---|---|---|---|
| 실기기 미측정 | — | — | — | — | — | — | 미확정 |

통과한 실제 모델만 사용자용 지원 목록에 추가한다. 한 기종 통과만으로 같은 브랜드 전체나 이름상 후속 기종까지 지원 확정으로 확대하지 않는다.
