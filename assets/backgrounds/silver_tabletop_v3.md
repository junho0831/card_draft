# Silver Tabletop

Generated for Card Draft with the built-in image generation tool on 2026-10-04.
No third-party reference art was used. The second pass retained the generated
silver perimeter and reduced central texture contrast for UI readability.

Runtime asset: `silver_tabletop_v3.png`.
The UI draws all cards, labels, counters, slots, and actions separately.
Silver/jade/garnet perimeter details are decorative, never touch targets.

Art direction: orthographic painted graphite stone table, engraved silver edge,
restrained gold fasteners, jade and garnet enamel, calm neutral center.
Match shared silver/amber UI frames; avoid blue illumination and busy marble
under small labels. This is a 2D texture, not a simulated 3D board.
