# 로컬 생성 모델 음원

게임 배포 플랫폼: 웹·모바일. 유료 서비스/API 사용 비용: 0원.

이 폴더의 Ogg는 공개 생성 모델의 실제 오디오 출력으로 제작한다. 기존 `original_v1`의 수학적 주파수 합성과 구분한다. 곡·효과음의 원본 프롬프트, 시드, 모델과 코드 버전, 생성 시간, 출력 SHA-256은 같은 이름의 JSON에 기록한다.

- 음악: ACE-Step/Ace-Step1.5, MIT. `ACE-Step-LICENSE.txt` 참조.
- 효과음 제작 모델: OpenMOSS-Team/MOSS-SoundEffect-v2.0, Apache 2.0. 실제 생성·저장이 완료된 효과음만 이 폴더에 포함한다.
- 모델 가중치·Python 환경은 배포하지 않는다.
- 특정 음악가나 기존 곡을 모방하도록 요청하지 않았고 참조 오디오는 입력하지 않았다.
- 후처리는 기존 오디오의 반복 경계 교차 혼합, 앞부분 무음 제거, 길이 편집, 음량·페이드 조절, Ogg 인코딩이다.
- 모델 사용 라이선스는 출력의 독점성·저작권 비침해를 보증하지 않는다.

공식 출처 및 재생성 명령은 `docs/local-model-audio.md`를 참조한다. 라이선스 때문에 다운로드하지 않은 ElevenLabs 미리보기는 포함하지 않는다.

2026-09-15 변경 원정: `ice_hit`, `shadow_hit`, `lightning_hit` 3개 효과음을 추가했다. 각 JSON에 실제 프롬프트·시드·50스텝·원본/배포 해시를 기록한다. 품질 검사에서 제외한 화살 생성 결과는 배포하지 않으며, 화살·바람 공격은 기존 `sword_hit`를 공유한다.
