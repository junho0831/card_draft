# Card Draft

5칸 필드 전투를 사용하는 싱글플레이 로그라이크 덱빌딩 RPG다. 인간·엘프·언데드 중 세력을 선택하고, 카드와 유물을 모아 두 막을 진행한다.

## 시작하기

Godot 4.6 이상에서 프로젝트 루트의 다음 명령으로 실행한다.

```bash
godot --path .
```

시작 씬은 `src/core/Main.tscn`이다. 설치·웹·Android 실행 및 저장 경로는 [실행과 테스트](docs/run-and-test.md)를 참고한다.

Android 설치 조건은 Android 7.0 이상, 64비트 ARM, OpenGL ES 3.0이다. 기종별 최소·권장 성능은 확정하지 않았다. [휴대폰 지원 조건](docs/device-support.md)에서 측정 범위를 확인한다.

## 게임 흐름

`새 런 → 세력·전략 선택 → 지도 → 전투·이벤트·상점·휴식 → 보스 → 결과`

- 일반 새 런은 2막, 총 10개 지점이다. 10~15분은 목표 시간이며 실측 달성을 의미하지 않는다.
- 처음에는 단계별 학습을 제공한다. 일반 런에서는 세력별 두 시작 전략을 선택한다.
- 카드 정의는 147장이다. 카드와 유물을 획득하며 다른 빌드로 전환할 수 있다.
- 첫 턴 기본 마나 2, 필드 5칸이며 적 영웅 체력을 0으로 만들면 승리한다.
- 전투당 세력 필살기 1회와 첫 3연계 피니시를 사용할 수 있다.
- 진행 상태는 로컬에 저장하며 이어하기로 복원한다.

화면 이동과 예외는 [서비스 흐름도](docs/service-flow.md), 수치와 규칙은 [게임 기획서](docs/game-design.md)를 기준으로 한다.

## 기본 조작

- 현재 화면은 가로 캔버스를 기준으로 표시한다. 전투의 적·아군 전열은 함께 고정 표시하며, 손패는 가로로 넘겨 확인한다.
- 모바일에서는 손패를 탭해 카드 전체와 효과를 확인한 뒤 `사용`을 누른다. 대상 선택 중에는 손패를 더 접어 전장을 넓게 보여준다.
- 데스크톱에서는 손패 클릭으로 사용하고 우클릭으로 상세를 확인한다.
- 공격 가능한 아군을 선택한 뒤 유효한 적 유닛 또는 영웅을 누른다. 적 선봉이 있으면 영웅 직접 공격이 제한된다.
- 장비·희생 등 대상이 필요한 행동은 아군을 선택해야 확정된다. 취소하면 자원을 소비하지 않는다.
- 학습의 `도움 보기`와 일반 전투의 `전투 정보`는 행동을 대신 실행하지 않는다.
- 시간 제한은 없다. 첫 학습 전투를 제외하고 행동 소진 시 조건에 따라 자동으로 턴을 종료한다.

상세한 터치·취소·화면 이동 규칙은 [모바일 조작](docs/mobile-controls.md), 음량·연출·자동 이동 조절은 [설정](docs/settings.md)을 참고한다.

## 개발과 검증

기본 회귀 검사는 실제 저장과 분리해서 실행한다.

```bash
godot --headless --path . -s res://tests/godot/run_tests.gd -- --test-data-dir=/tmp/card-draft-check
```

UI를 변경했을 때는 실제 렌더링과 입력을, 런 흐름을 변경했을 때는 자동 플레이를 추가 확인한다. 명령과 해석 범위는 [실행과 테스트](docs/run-and-test.md)에 모았다. 자동 검사 통과는 실물 휴대폰의 조작감·성능이나 신규 사용자의 이해도를 보장하지 않는다.
